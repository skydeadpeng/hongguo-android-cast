# Android 播放取源：独立匿名登记兼容路径

## 适用问题

下一集已经自动打开，但 App 模型接口返回 HTTP 200 空正文，导致未开始播放。连播开关、完整队列及完成回调不能代替下一集的有效片源。

## 实现

- 旧 multi 模型路径成功时保持原行为；只有其模型请求的空正文错误，且 Android 已注册专用原生入口时，才尝试登记兼容路径。桌面端不自动调用 Android 入口。
- 每次兼容取源创建独立、只在内存保留的匿名设备身份，先完成官方设备登记，再使用返回的设备与安装编号请求固定的单集模型接口。不读取红果登录账号、会话库或自建同步凭据。
- 原生只接收所选分集编号，只返回对应模型中的必要媒体字段；不把登记身份或会话数据传给页面。单集模型使用其对应的 URL 编码与媒体参数解析，继续校验 HTTPS 域名、分集身份、真实分辨率和手动下载清晰度。
- 旧模型阶段最多 6 秒，登记与单集模型共享最多 20 秒，页面整轮最多 28 秒；原生分集解析仍保留 30 秒整体上限。取消、超时、换集与退出会终止对应任务，迟到结果没有播放资格。
- 未更改自动下一集的完成回调；失败时保留当前分集，不把跳过失败分集冒充成功连播。

## 验证

模拟器验收记录和实际取源对照保存在本工作区 `verification/playback-stability-20261027/`；完整结果以该目录的 VERIFICATION.txt 为准。匿名模型获取成功不等于视频已解码或连续播放成功。
