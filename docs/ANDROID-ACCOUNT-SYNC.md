# 红果官方账号与同步（Android 0.12.13）

## 登录

手机/TV进入「关于 → 红果账号」，输入中国大陆11位手机号（+86），主动点击“获取短信验证码”，在设备上填写收到的验证码后登录。验证码不发到聊天，不写入浏览器或磁盘。发送前会先匿名登记设备；失败不会假装发码成功，也不自动重发。

明确拒绝、限流和网络结果不确定有不同状态；结果不确定时保留防重复发送倒计时。验证码错误可重新输入，换号/取消会中止旧请求并清内存验证码。若请求结果不确定但短信已收到，可以直接输入该验证码登录；原防重发倒计时仍保留，不强迫再次发码。

## 追加短信验证

若红果要求验证，页面显示本次上游返回的短信收件号码和内容。用户用登录手机号在短信App发送后，回到红果点“我已发送”。查询每3秒一次，单轮最多90秒，挑战10分钟到期（总期限和单轮均受单调时钟约束，系统时间回拨不延长）；可以取消或稍后在期限内再查询。

临时切到短信App不会丢弃仍有效的内存挑战；进程重建、明确取消或换号后重新登录。不把二维码当作官方App扫码授权，不替用户发送上行短信。

## 同步与记录

登录后自动读取官方收藏、历史及进度，也可点“立即同步”。先完整读取有效分页再合并；失败、半截列表和格式错误不当成空库覆盖。离线继续保存本机账号记录，待同步队列写盘后保留；历史和进度两次服务端确认才清对应revision，迟到确认不会清掉新进度。

游客和各官方UID各有独立库，登录不自动上传游客记录。需要迁移时，点击“导入本机记录”并确认，导入收藏与观看记录；本机原库保留。结果分别显示收藏/历史导入数及剩余可重试数，去重水印落盘，重复导入不恢复已经取消的收藏。同一账号较新的本地未上传进度优先保留，按更新时间解决冲突，不用“集数更大”判断重看。本机播放中每15秒保存实际进度，暂停和已确认的跳转立即保存；同步真实分集时长及已知分季标记。投屏以接收端确认的进度/分集时长为准，合并投屏不把整段时长记成单集时长。

大库界面展示最近最多200项/每类96KiB，显示这是投影而非全库；全部有效记录仍在本机账号库。详情按本剧ID点查完整库，较旧收藏与进度不因界面裁剪丢失。

同账号同步刷新后，详情会重新点查被投影裁剪的旧剧收藏/进度，不重载片源或抢走已选分集。退出后切回原游客记录，官方凭据持久注销，账号本地库留存。会话失效要求重新登录并结束旧同步等待标记；网络中断前已确认的会话刷新仍会持久化，退出/取消/切号/失效后的迟到会话不会复活。不向新账号/游客写入旧UID迟到操作，读库也检查账号epoch，防止A→B→A切回时接收中间账号的结果。

## 存储与旧自建账号

官方Cookie/token使用独立Android Keystore key加密，磁盘只保存密文，不给网页、CDN、投屏或原自建服务器。OTP/追加验证票据仅内存保存，不出现在日志、URL或本地存储。

自建同步功能自0.12.11起移除；旧文件不读取、不解密、不联网、不删除，也不自动并入官方账号。历史服务源码仍保留，但当前Android不连接它。

## 验收边界

完整Passport/TTEncrypt向量、模拟短信/MFA、会话保存失败、取消/切号/退出、库分页/双确认/磁盘失败和实际React手机/TV界面有回归覆盖。真实匿名登记已返回HTTP200；这不代替真实短信、风控/MFA、跨设备云写及实体TV验收。真实发码和登录由用户在设备主动操作，不由构建工具触发。
