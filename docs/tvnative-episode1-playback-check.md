# tvNative 第 1 集重新取源排查

2026-11-13，TCL tc8000 / Android 11 / 红果原生版 0.1.19。

- 素材：[《无声夫君锦绣妻》](https://hongguoduanju.com/detail?series_id=7701280092181253144)第 1 集；独立测试目录由官网公开播放流程真实下载，7,873,710 字节，声明时长 110.899 秒。未使用测试画面或记录带签名的媒体地址。
- 同一视频在电视上的 MediaExtractor 报告视频 `video/avc`、音频 `audio/ffmpeg`。旧版验证器拒绝音轨并触发自动重新取源；新版仅在 MP4 的 `mp4a/esds` 独立确认 AAC-LC 时接受该别名，时长、加密状态、完整样本和时间轴验证继续执行。
- 用同一份视频运行原验证器：拒绝（退出 3）。运行新验证器：通过（退出 0）。独立 ADB 播放探针在调用 prepare/start 前设播放器音量为零，真机在离屏表面输出 107 个不同时间戳的视频帧，进度从 1.350 秒推进到 4.347 秒。
- 原版停在重新取源时未收到最终错误。模拟阻塞重试的回归用例在原代码失败，修复后通过：自动重新取源最多等待 30 秒，迟到结果不进入播放，下载阶段不受该上限影响。
- 普通及非流式 ADB 安装测试 APK 均返回 `INSTALL_FAILED_VERIFICATION_FAILURE`。没有覆盖真机正式应用；真机探针验证不等同于应用内起播验证。
