Windows FFmpeg / FFprobe distribution (hongguo-downloader 2.3 fork)
FFmpeg 9.0.2 essentials build (GPLv3-or-later) with libx264.

Provenance of this fork's binaries: prebuilt official "essentials" distribution
from Gyan.dev, https://www.gyan.dev/ffmpeg/builds/packages/ffmpeg-9.0.2-essentials_build.zip
(downloaded 2026-11-01, archive size 114768076 bytes).
SHA256:
  ffmpeg.exe   3256173f3f8bffd7df12227c68adf68025edb1832273a9530688a7bb1ed8edec
  ffprobe.exe  f0d36ecbbdd3bcfac3efa078c96c7271c2e68b3810595552ac3b7f17e9a65c52
The upstream project historically shipped self-compiled binaries (see
scripts/build-ffmpeg-source-win.sh); this fork switched to the official Gyan
essentials build because the cross-compilation toolchain could not be fetched
in the maintainer's network. The essentials build includes more codec
libraries than the upstream minimal build; no non-free components are used.
Gyan.dev license text: WINDOWS-GYAN-LICENSE.txt.
Software H.264 encoding uses the bundled libx264.
